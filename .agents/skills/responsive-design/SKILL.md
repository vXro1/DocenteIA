# Responsive Design

1. Diseñar primero para pantallas pequeñas cuando sea apropiado.
2. Utilizar layouts flexibles con Flexbox y CSS Grid.
3. Evitar anchos fijos que provoquen desbordamiento.
4. Comprobar navegación, formularios, tablas y diálogos en móvil.
5. Utilizar media queries cuando sean necesarias.
6. Evitar texto ilegible y objetivos táctiles demasiado pequeños.
7. Comprobar el zoom y el reflujo del contenido.
8. No ocultar información esencial en pantallas pequeñas.
9. Verificar la interfaz en móvil, tableta y escritorio.
