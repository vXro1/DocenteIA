# Accessibility

1. Utilizar HTML semántico.
2. Asociar cada campo con una etiqueta accesible.
3. Permitir navegación por teclado.
4. Mantener indicadores de foco visibles.
5. Proporcionar nombres accesibles a controles con iconos.
6. No comunicar estados utilizando solamente colores.
7. Mantener contraste suficiente.
8. Gestionar el foco en diálogos y ventanas modales.
9. Añadir textos alternativos apropiados a imágenes informativas.
10. Respetar las preferencias de movimiento reducido.
11. Utilizar ARIA cuando HTML nativo no sea suficiente.
12. No afirmar conformidad WCAG sin realizar las comprobaciones pertinentes.
